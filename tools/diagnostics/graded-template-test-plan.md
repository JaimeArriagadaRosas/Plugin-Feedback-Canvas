# Cuatro pruebas de plantillas inglesas

1. Standard Class, 94/100, rango alto.
2. Detailed Feedback, 73/100, rango medio.
3. Peer Review, 42/100, rango bajo.
4. Standard Class con `{{grade}}` y `{{course_average}}`, 88/100 y promedio sintético 74/100.

Entregas sintéticas aisladas y feedbacks guardados solo en memoria. Cada caso debe ejecutar `FeedbackGenerationService.generateFeedback` y comprobar el prompt y la respuesta, sin publicar en Canvas ni persistir los feedbacks en PostgreSQL. El promedio no debe proceder de una media de una tarea.
