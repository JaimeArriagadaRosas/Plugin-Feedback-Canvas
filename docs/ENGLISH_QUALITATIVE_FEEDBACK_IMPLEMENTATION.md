# English qualitative feedback parity — implementation record

Date: 2026-10-25. Working branch: `feat/english-qualitative-feedback-parity`, based exclusively on `english-version` (`3726700`). Spanish `main` (`0290c3c`) was consulted as a reference but never merged or rebased into this English branch. The English production branch is unchanged.

## Functional changes
- `FeedbackGenerationService` now routes submitted, ungraded work to `UngradedFeedbackService`, including pending-review quiz submissions. A numeric grade of zero is preserved and still follows the graded path. A blank/absent grade is distinct from zero.
- `SubmissionContentProcessor` and `DocumentToMarkdownConverter` extract actual text from PDF, PPTX, DOCX, text and HTML; images/visual PDF material are attached to compatible Gemini requests. Unavailable, empty, oversized and unsupported attachments fail before an AI evaluation. File names use Canvas `display_name` ahead of deduplicated `filename`.
- `QuizAnswerFacade` reads verified Classic Quiz answers, including the Canvas Student Analysis report fallback with stale-report checks. `SubmissionAttachmentDownloader` authenticates trusted Canvas downloads and controls redirects.
- `QualitativeFeedbackEvaluator`, `RubricContextBuilder` and `FeedbackResponseNormalizer` use English prompts, optional rubric and evidence-driven feedback without inventing grades or author identity. Recipient name comes from Canvas, not names in attached documents. The resulting feedback is saved as a pending draft.
- Database migration 025 permits qualitative drafts without a template. `FeedbackMutationService` does not substitute a grade for a truly ungraded comment.
- Gemini fallback defaults to `gemini-3.6-flash`; qualitative responses cannot silently become mock fallback text. One-request diagnostic mode bypasses automatic retries, while normal requests retain bounded exponential backoff.
- SpeedGrader handles null grade without displaying it as zero, labels it `Not graded` and treats the template as not required for qualitative feedback.
- English installer now supports safe port inspection, reuse of project-owned services and explicitly confirmed PID termination, without killing unrelated processes automatically.
- Local seeder creates distinct synthetic documents per student and assignment for PDF/PPTX/XLSX/ZIP; duplicate bytes no longer arise merely from copies of a common master. Existing Canvas data is not regenerated by this code change.

## Known limitations and remaining manual tests
- The `english-version` environment was cleaned by option 5 and is not running. This implementation has **not** yet been exercised against a freshly seeded English Canvas instance with a real Gemini request. Ruby seed generation against live Rails and verification of database migration after fresh installation remain to be tested.
- Classic Quizzes has simulated and unit coverage; New Quizzes and real group submission handling are not proven. Student Analysis reports can be stale, requiring regeneration in Canvas.
- Gemini HTTP 503 is a known external temporary service overload/unavailability, not proof of exceeding API quota. References: https://ai.google.dev/gemini-api/docs/troubleshooting and https://ai.google.dev/gemini-api/docs/api-errors. Do not assume retries resolve every 503.
- Required manual acceptance: start local Canvas, verify native English language, seed isolated assignments, generate a single real draft for PDF/PPTX/text/Classic Quiz, verify accurate student name, no Canvas grade mutation, no comment published without teacher approval, and confirm controlled startup/cleanup.
- The English production branch `english-version` must only be updated by a later approved merge of this English feature branch once these checks are accepted; never merge Spanish `main`.
